# مقصف الفُسحة 🥪 | مشروع الطالبة: زينة اللبدي (الصف الثامن)

موقع ويب تفاعلي ذكي ومتطور لمقصف المدرسة الإعدادية، صُمم ونُفّذ خصيصاً كـ **مشروع للطالبة المتميزة: زينة اللبدي (الصف الثامن - أ)**.

يتيح الموقع لطلاب المدرسة طلب وجباتهم وساندويشاتهم ومشروباتهم مسبقاً لاستلامها في **الفسحة المدرسية الوحيدة المقررة الساعة 10:00 صباحاً** دون الوقوف في الطوابير، مع ربط سحابي فوري عبر **Supabase Realtime** ولوحة تحكم حية لصاحب المقصف ونظام تسجيل حسابات الطلاب وقائمة الدخول السريع.

---

## 🌟 الميزات والمواصفات الكاملة

1. **إبراز اسم صاحبة ومصممة المشروع (زينة اللبدي ⭐)**:
   - تم إبراز اسم الطالبة **«زينة اللبدي»** في الترويسة الرئيسية، لافتات الترحيب، تذاكر الاستلام، وتذييل الموقع الرسمي كصاحبة الفكرة والتصميم لمقصف الصف الثامن.

2. **فسحة مدرسية واحدة وموحدة (الساعة 10:00 صباحاً)**:
   - تم ضبط النظام ليعتمد موعداً واحداً فقط للفسحة المدرسية: **الساعة 10:00 صباحاً**.
   - إضافة **ويدجت عد تنازلي تفاعلي (Live Countdown Timer)** يحسب الثواني والدقائق والساعات المتبقية على رنين جرس فسحة العاشرة صباحاً لحظة بلحظة.

3. **كرت الاستلام الرقمي التفاعلي وإصلاح الطباعة (Pickup Voucher)**:
   - كرت استلام أنيق يوضح رقم الطلب، بيانات الطالب وصفه وشعبته، موعد الفسحة، والباركود المدرسي.
   - **مسار متابعة من 4 مراحل مرئية:** (1) تم الطلب ⏳ -> (2) بالمطبخ 👨‍🍳 -> (3) جاهز للاستلام 🔔 -> (4) تم الاستلام ✅.
   - **طباعة نظيفة 100%:** طباعة كرت الاستلام فقط دون عناصر الموقع المشوشة عبر إعدادات `@media print` المخصصة مع مؤثر صوتي للطباعة.
   - زر مباشر في شريط التنقل `كرت استلامي 🎫` لفتح كرت آخر طلب للطالب في أي وقت.

4. **نظام الدخول السريع والحسابات المدرسية (Quick Login & Auth)**:
   - قائمة **الدخول السريع (1-Click Login)** للدخول بنقرة واحدة بحساب زينة اللبدي، صاحب المقصف، أو أي طالب مضاف.
   - خيار حفظ الحساب في قائمة الدخول السريع متاح في كلٍ من تسجيل الدخول وإنشاء حساب جديد.
   - إمكانية حذف الحسابات المضافة وتخصيص قائمة الدخول السريع.

5. **الربط السحابي مع Supabase والمزامنة اللحظية (Supabase Realtime)**:
   - ربط سحابي هجين وفوري مع منصة Supabase عبر PostgREST و WebSockets.
   - تحديث فوري بين أجهزة الطلاب وشاشة مطبخ المقصف في الوقت الحقيقي.
   - سكربت `supabase_setup.sql` جاهز لتفعيل الجداول وسياسات الأمان وتغذية الـ 29 صنفاً.

6. **لوحة تحكم كاملة لصاحب المقصف وإدارة المخزون**:
   - متابعة طابور الطلبات الحية وقبولها وتجهيزها وتسليمها.
   - إدارة توفر الأصناف في المقصف بنقرة زر (متوفر للطلب / نفد مؤقتاً).
   - تعديل الأسعار، المكونات، وأوقات التحضير، أو إضافة وحذف وجبات جديدة.

7. **صور SVG محلية فائقة الدقة 100% لكافة الأصناف (29 صنفاً)**:
   - تغطية شاملة لكافة الأقسام: الساندويشات والبيتزا، السلطات والمقبلات (سيزر، سلطة عربية، يلنجي، سوشي)، الباستا (معكرونة بالصلصة الحمراء، فوتتشيني، ماك أند تشيز، بطاطا مهروسة)، العصائر والمشروبات (حليب وفراولة، حليب وموز، عصير فواكه، برتقال، تفاح، شنينه، شنينه فراولة، ماء صغير)، طبق اليوم من الأرز، والحلويات (براوني، كوكيز، ليزي كيك، كب كيك، كورن فليكس بار).
   - كل صنف يتضمن **وصف الصورة التفصيلي** الإلزامي باللغة العربية.

8. **أنيميشن وتفاعلية فائقة**:
   - حركات رفع عائمة (`Floating Elements`)، وميض نبض الطلب الجاهز (`ready-pulse`)، ظهور ارتدادي للكرت (`ticket-pop`)، ومؤثرات الاحتفال بالكونفيتي ومؤثرات الصوت المدمجة.
